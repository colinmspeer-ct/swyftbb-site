# Swyft Business Broker website

Static marketing site for **Swyft Business Broker**, the value-added business-broker offer of Swyft (Swyft Solutions LLC), led by Colin Speer. It explains how Swyft helps owners raise the value of a business before a sale and helps buyers grow a business after a purchase, using the services Swyft HQ runs today (door-to-door sales teams and Swyft International placements). It links back to https://swyft-hq.com/ for the growth work.

## What it is

- Plain HTML, one stylesheet (`assets/site.css`), and one small script (`assets/contact.js`, contact form only). No framework, no npm, no build step needed to serve it.
- Hosted as a **GitHub Pages** static site, served from the repository root.
- System fonts only. No analytics, no cookies, no third-party requests.

## Preview

Project-site preview: **https://colinmspeer-ct.github.io/swyftbb-site/**

All internal links and asset paths are relative so the site works under the `/swyftbb-site/` sub-path.

`404.html` is the exception: GitHub Pages serves it at whatever URL was requested, so it uses a small inline script to set a `<base>` (`/swyftbb-site/` on `*.github.io`, `/` on a custom domain).

## Custom domain: do not attach yet

The production domain is **swyftbb.com**. **Do not attach it until Colin approves the preview.** That means:

- no DNS changes.

## Canonical URLs

`canonical`, `og:url`, `og:image`, JSON-LD URLs, `sitemap.xml` and `robots.txt` already point at the production host `https://swyftbb.com/` (trailing-slash directory URLs). While only the preview is live, those URLs will not resolve yet; that is expected. To switch hosts, change `SITE_URL` in `scripts/build.py` and rebuild.

## Editing and rebuilding

Pages are generated by `scripts/build.py` so the header, footer and meta tags stay consistent. The built HTML is committed, so GitHub Pages serves it directly.

```sh
python3 scripts/build.py     # regenerate all HTML, sitemap.xml, robots.txt (stdlib only)
python3 scripts/make_og.py   # regenerate assets/og-image.png (needs Pillow)
```

Edit copy in `scripts/build.py`, then rebuild. Edit styles in `assets/site.css` directly.

## Contact form

There is no backend. The form posts to a `mailto:` address (`colin@swyft-hq.com`) and works without JavaScript. With JavaScript, `assets/contact.js` opens the user's email app with a subject and a readable body. Email and phone are shown on the page as plain fallbacks.

## Content rules

The site intentionally does not include: invented statistics, testimonials, client names, case studies, deal history, listings, a brokerage fee, license claims, or a street address. Services named are only those live on swyft-hq.com. Keep it that way when editing.
